## Next milestones

Finish Phase 1 on the repair branch and open a reviewable PR. Then address Phase 2 prerequisites: generate and review a workspace lockfile in a stable network-enabled environment; validate environment variables; add migration version tracking without rewriting the existing initial migration; and run clean-clone PostgreSQL-backed CI. Keep production deployment and real payment/email capabilities disabled during this work.
